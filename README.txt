MUZAMIL BATTLEGROUND 3D — پہلا قابلِ کھیل 3D پروٹوٹائپ

اہم:
- یہ ایک حقیقی 3D سنگل پلیئر ڈیمو ہے، گیلری نہیں۔
- چلنے، دشمنوں کے قریب جانے، فائر، جمپ اور ری لوڈ کے کنٹرول شامل ہیں۔
- Fire, Snow, Forest, Shadow سوٹس اور Gold, Ice, Red, Black گن اسکنز اس ڈیمو میں مفت ہیں۔
- یہ PUBG کی اصل فائلیں یا اثاثے استعمال نہیں کرتا۔
- ابھی آن لائن ملٹی پلیئر، گاڑیاں، بڑے نقشے، اکاؤنٹ، لابی اور مکمل PUBG درجے کے گرافکس شامل نہیں۔
- Three.js انٹرنیٹ سے CDN کے ذریعے لوڈ ہوتی ہے، اس لیے پہلی بار کھولتے وقت انٹرنیٹ ضروری ہے۔

GitHub Pages پر چلانے کے لیے:
1) ZIP extract کریں۔
2) اندر کی تمام فائلیں GitHub repository کے root میں upload کریں۔
3) Settings > Pages میں main branch اور /(root) منتخب کریں۔
4) Pages کے لنک کو Chrome میں کھولیں۔
5) Chrome menu > Install app یا Add to Home screen دبائیں۔

یہ APK نہیں؛ Home Screen سے standalone ویب ایپ کی طرح کھلے گی۔
